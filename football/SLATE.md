# Slate: 100 stories, 4 sets of 25

Two lists per set, each owning a sub-theme so no story repeats. Run settings: `slate/runs.json`. Each run fills its own list in `slate/<run>.md` (id, title, hook, sources, status: `idea` → `scripted` → `rendered`, or `blocked: <why>`).

| Set | Name | Runs |
| --- | --- | --- |
| s1 | Wait, that's the rule? | s1a (catching, passing, fumbles, replay) · s1b (kicking, scoring, clock, tiebreakers, new rules) |
| s2 | This season (2026) | s2a (September–October) · s2b (November–now) |
| s3 | The strange years | s3a (the 2020 COVID season; s3_01 Kendall Hinton is the template) · s3b (strikes, weather, relocations, everything else) |
| s4 | Endings nobody forgets | s4a (lateral miracles and wild last plays) · s4b (clock, overtime and standings chaos, incl. the Raiders–Chargers tie scenario) |
